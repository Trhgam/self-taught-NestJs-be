#  self-taught-NestJs-be

Dự án nghiên cứu và xây dựng hệ thống Backend chuyên sâu với **NestJS**, **TypeScript**, **PostgreSQL** và **Prisma ORM**. Mục tiêu cốt lõi của repository này là chuẩn hóa quy trình phát triển từ quản lý mã nguồn đến triển khai cơ sở dữ liệu thực tế.

---

## Tech Stack & Tools

| Công nghệ              | Vai trò                                        |
| :--------------------- | :--------------------------------------------- |
| **NestJS**             | Framework chính (Node.js) với kiến trúc Module |
| **TypeScript**         | Ngôn ngữ lập trình chính (Strict Mode)         |
| **Prisma**             | ORM hiện đại, Type-safe cho PostgreSQL         |
| **PostgreSQL**         | Hệ quản trị cơ sở dữ liệu quan hệ chính        |
| **Husky & Commitlint** | Kiểm soát Git hooks & Chuẩn hóa Commit Message |
| **ESLint & Prettier**  | Đảm bảo chất lượng code & Định dạng thống nhất |

---

##  Roadmap & Content

Dự án được triển khai qua các giai đoạn học tập:

### 1. Fundamentals & Architecture

- [ ] Cấu trúc Module, Controller, Service.
- [ ] Dependency Injection (DI) & Inversion of Control (IoC).
- [ ] Custom Decorators & Providers.

### 2. Database Layer (Prisma & PostgreSQL)

- [ ] Thiết lập PostgreSQL (Dockerized).
- [ ] Thiết kế Prisma Schema & Relationships (1:1, 1:n, n:n).
- [ ] Quản lý Migrations & Seeding dữ liệu.

### 3. API Standard & Security

- [ ] Data Transfer Object (DTO) & Global Validation Pipes.
- [ ] Authentication với JWT & Passport.js.
- [ ] Authorization (RBAC - Role-based Access Control) bằng Guards.

### 4. Advanced Features

- [ ] Middleware, Interceptors (Logging & Transform).
- [ ] Exception Filters (Xử lý lỗi tập trung).
- [ ] Database Transactions với Prisma.
