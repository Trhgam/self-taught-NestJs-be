### Giới thiệu về Controller trong NestJS Controller

là một phần quan trọng trong kiến trúc của NestJS, chịu trách nhiệm xử lý các yêu cầu HTTP và trả về phản hồi cho client. Controller định nghĩa các route và phương thức để xử lý các yêu cầu từ client, thường được sử dụng để tương tác với các service để thực hiện các logic nghiệp vụ.

Trong NestJS, bạn có thể tạo một controller bằng cách sử dụng decorator `@Controller()`. Mỗi phương thức trong controller có thể được trang trí bằng các decorator như `@Get()`, `@Post()`, `@Put()`, `@Delete()`, v.v., để xác định loại yêu cầu HTTP mà phương thức đó sẽ xử lý.
Dưới đây là một ví dụ về cách tạo một controller trong NestJS:

````typescript
import { Controller, Get } from '@nestjs/common';

@Controller('products')
export class ProductsController {
    @Get()
    findAll(): string {
        return 'This action returns all products';
    }
    }
    ```

---
````

Trong ví dụ trên, chúng ta đã tạo một controller có tên `ProductsController` với một route là `/products`. Phương thức `findAll()` được dùng Decorator `@Get()`, có nghĩa là nó sẽ xử lý các yêu cầu GET đến route `/products` và trả về một chuỗi thông báo.
Bạn cũng có thể thêm các phương thức khác để xử lý các loại yêu cầu khác nhau, ví dụ:

```typescript
import { Controller, Get, Post, Put, Delete } from "@nestjs/common";

@Controller("products")
export class ProductsController {
  @Get()
  findAll(): string {
    return "This action returns all products";
  }

  @Post()
  create(): string {
    return "This action creates a new product";
  }

  @Put(":id")
  update(): string {
    return "This action updates a product";
  }

  @Delete(":id")
  remove(): string {
    return "This action removes a product";
  }
}
```

---

Trong ví dụ trên, chúng ta đã thêm các phương thức `create()`, `update()`, và `remove()` để xử lý các yêu cầu POST, PUT, và DELETE tương ứng. Các route được định nghĩa với tham số `:id` để cho phép xử lý các yêu cầu cụ thể cho từng sản phẩm dựa trên ID của nó.
Để sử dụng controller này, bạn cần đăng ký nó trong module của bạn. Ví dụ, nếu bạn có một module `ProductModule`, bạn có thể đăng ký controller như sau:

```typescript
import { Module } from "@nestjs/common";
import { ProductsController } from "./products.controller";

@Module({
  imports: [],
  controllers: [ProductsController],
  providers: [],
  exports: [],
})
export class ProductModule {}
```
