### 1. Cơ chế hoạt động
   Khi bạn nhấn Ctrl + S để lưu file code:

Watcher: Một bộ phận giám sát (thường là ts-node-dev hoặc webpack trong NestJS) sẽ phát hiện file đã bị thay đổi.

Re-compile: Nó chỉ biên dịch lại những phần code vừa thay đổi.

Inject: Nó "bơm" phần code mới đó vào tiến trình đang chạy.

### 2. Sự khác biệt giữa các loại "Reload"
Trong giới lập trình, người ta thường phân biệt 3 khái niệm dễ nhầm lẫn này:

- **Hot Reload**: Chỉ thay đổi đúng đoạn code bạn vừa sửa mà không làm khởi động lại toàn bộ hệ thống. Ví dụ, nếu bạn đang ở một trang web và thay đổi một component, hot reload sẽ cập nhật component đó mà không làm bạn phải tải lại trang.Giữ nguyên trạng thái (ví dụ: bạn đang điền dở một cái Form thì cái Form đó vẫn còn nguyên dữ liệu).

- **Live Reload**: Tự động tải lại toàn bộ ứng dụng khi có thay đổi trong quá trình phát triển.Server tự phát hiện thay đổi, tự khởi động lại toàn bộ và trình duyệt tự F5. Điều này có nghĩa là bạn sẽ mất trạng thái hiện tại (ví dụ: dữ liệu đã nhập, vị trí trên trang) mỗi khi có thay đổi.

- **Cold Reload**: Bạn tắt server (Ctrl+C), sau đó gõ lệnh chạy lại từ đầu.	Mất sạch dữ liệu tạm thời, tốn thời gian chờ. Điều này thường xảy ra ở backend, nơi mà ứng dụng sẽ được khởi động lại hoàn toàn để áp dụng các thay đổi mới.

### 3. Cách sử dụng Hot Reload trong NestJS
Để sử dụng hot reload trong NestJS, bạn cần cài đặt một số công cụ hỗ trợ và cấu hình.

#### Cài đặt và chạy lệnh

```ts
$ npm i --save-dev webpack-node-externals run-script-webpack-plugin webpack
```
Sau đó, bạn cần tạo 1 file cấu hình webpack-hmr.config.js ở thư mục gốc của dự án với nội dung như sau:

```ts
const nodeExternals = require('webpack-node-externals');
const { RunScriptWebpackPlugin } = require('run-script-webpack-plugin');

module.exports = function (options, webpack) {
  return {
    ...options,
    entry: ['webpack/hot/poll?100', options.entry],
    externals: [
      nodeExternals({
        allowlist: ['webpack/hot/poll?100'],
      }),
    ],
    plugins: [
      ...options.plugins,
      new webpack.HotModuleReplacementPlugin(),
      new webpack.WatchIgnorePlugin({
        paths: [/\.js$/, /\.d\.ts$/],
      }),
      new RunScriptWebpackPlugin({ name: options.output.filename, autoRestart: false }),
    ],
  };
};
```
Cuối cùng, bạn cần thay đổi lệnh start:dev trong file package.json như sau:

```json
"start:dev": "nest build --webpack --webpackPath webpack-hmr.config.js --watch",
```
