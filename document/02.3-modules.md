### Modules in NestJS
Trong NestJS, một module là một class được đánh dấu bằng decorator `@Module()`. Nó đóng vai trò như một cách để tổ chức các thành phần liên quan, chẳng hạn như controllers và providers, thành các khối chức năng gắn kết. Các modules giúp cấu trúc ứng dụng và quản lý các phụ thuộc (dependencies) một cách hiệu quả.

---#### Example of a Module
```typescript
import { Module } from '@nestjs/common';

@Module({
  // Module configuration
})
export class ProductModule {} ;
```
---

### Các thành phần chính trong một Module:

#### Controllers
Controllers chịu trách nhiệm xử lý các yêu cầu đến và trả về phản hồi. Chúng thường được sử dụng để định nghĩa các route và logic liên quan đến việc xử lý HTTP requests.
#### Providers (Services) 
Providers là các class có thể được inject vào controllers hoặc các providers khác để cung cấp các chức năng cụ thể, chẳng hạn như truy cập cơ sở dữ liệu hoặc thực hiện các phép tính phức tạp. Chúng thường được sử dụng để tách biệt logic kinh doanh khỏi controllers.
#### Imports
Một module có thể import các module khác để sử dụng các controllers và providers được định nghĩa trong đó. Điều này giúp tái sử dụng mã và tổ chức ứng dụng một cách hiệu quả.
#### Exports
Một module có thể export các controllers hoặc providers để chúng có thể được sử dụng bởi các module khác. Điều này cho phép chia sẻ các thành phần giữa các module mà không cần phải import toàn bộ module.


```ts
import { Module } from '@nestjs/common';
import { AppController } from './app.controller';
import { AppService } from './app.service';

@Module({
  imports: [],      // Các module khác
  controllers: [AppController], // Các controller
  providers: [AppService],    // Các service (logic)
  exports: []       // Những gì muốn chia sẻ ra ngoài
})
export class AppModule {}
```
